# Radio Finder

Android-App: Lied eingeben, die App schaut bei ein paar hundert Internetradios nach, wo es **gerade läuft**, und spielt den Sender ab. Läuft im Hintergrund und in Android Auto.

## Installieren
1. Unter **Releases** (rechts auf der Projektseite) die neueste `RadioFinder.apk` herunterladen
2. Öffnen → Installation aus dieser Quelle erlauben → Installieren

## Android Auto
Weil die App nicht aus dem Play Store kommt, einmalig:
1. Android Auto Einstellungen → ganz unten 10× auf **Version** tippen → Entwicklermodus
2. Oben rechts ⋮ → **Entwicklereinstellungen** → **Unbekannte Quellen** an

Danach taucht Radio Finder in Android Auto auf. Suchen per Sprache: „Hey Google, spiel *Lied* auf Radio Finder“.

## Woher kommen die Sender?
Senderliste von radio-browser.info (deutsche Sender, weltweit beliebte, Dance und Remix). Der laufende Titel wird aus der Titelanzeige gelesen, die die Sender mitschicken.
